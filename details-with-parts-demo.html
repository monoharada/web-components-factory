🎨 Web Components ::part() を活用したアコーディオン

デフォルトスタイル

::part() とは何ですか？

::part() は Web Components の Shadow DOM 内の要素を外部からスタイリングするための CSS 擬似要素です。

これにより、コンポーネントの作者が意図的に公開した部分のみを、利用者が自由にカスタマイズできます。

 なぜクラスより ::part() が良いのか？
  • カプセル化の維持: Shadow DOM の境界を保ちながら、特定の部分だけを公開
  • 意図的な API: コンポーネント作者が「どこがカスタマイズ可能か」を明示的に定義
  • セマンティック: part属性で要素の役割を意味的に表現
  • スコープの明確化: グローバルなクラス名の衝突を避ける
 実装例 
// コンポーネント側
<summary part="summary">
  <span part="icon">
    <svg part="icon-svg">...</svg>
  </span>
  <slot name="header"></slot>
</summary>

// 利用側のCSS
component::part(summary) { }
component::part(icon) { }
component::part(icon-svg) { }

カスタムテーマ（グラデーション）

カスタムスタイルの適用
::part() を使うことで、Shadow DOM 内の要素を外部から自由にスタイリングできます。 このセクションはグラデーションテーマを適用しています。
テーマの切り替え
親要素にクラスを追加するだけで、子コンポーネントのスタイルを一括で変更できます。 Shadow DOM のカプセル化を維持しながら、柔軟なカスタマイズが可能です。

ダークテーマ

ダークモード対応
::part() を使えば、ダークモードの実装も簡単です。 親要素に .dark-theme クラスを付けるだけで、すべての子要素が適切にスタイリングされます。
アクセシビリティ
ダークモードでも適切なコントラスト比を維持し、 WCAG 2.1 AA の基準を満たすようにスタイリングされています。

公開されている part 一覧

part名 要素 説明
details details アコーディオン全体のコンテナ
summary summary クリック可能なヘッダー部分
icon span アイコンのコンテナ
icon-svg svg 矢印アイコンのSVG
header-text span ヘッダーテキストのラッパー
content div 展開されるコンテンツエリア
return-button button 先頭に戻るボタン
return-icon svg 戻るボタンのアイコン
return-text span 戻るボタンのテキスト
