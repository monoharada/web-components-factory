説明リスト

項目名1
これは項目1の説明文です。説明リストは用語とその説明をセットで表示するのに適しています。
項目名2
これは項目2の説明文です。マーカーの種類を変更することで、ブレットや連番を表示できます。
項目名3
これは項目3の説明文です。HTMLのdl、dt、dd要素に対応したコンポーネントです。

使用例

基本的な使い方

<dl class="dads-description-list">
  <div class="dads-description-list__item">
    <dt>項目名1</dt>
    <dd>これは項目1の説明文です。</dd>
  </div>
  <div class="dads-description-list__item">
    <dt>項目名2</dt>
    <dd>これは項目2の説明文です。</dd>
  </div>
</dl>

ブレット付き

マーカーとしてブレットを表示する場合は、data-marker="bullet"を指定します。

<dl class="dads-description-list" data-marker="bullet">
  <div class="dads-description-list__item">
    <dt>項目名1</dt>
    <dd>これは項目1の説明文です。</dd>
  </div>
  <div class="dads-description-list__item">
    <dt>項目名2</dt>
    <dd>これは項目2の説明文です。</dd>
  </div>
</dl>

カスタムマーカー付き

独自のマーカーを使用する場合は、data-marker="custom"を指定します。カスタムマーカーはdt要素の最初の<span>要素で指定します。

<dl class="dads-description-list" data-marker="custom">
  <div class="dads-description-list__item">
    <dt><span>1.</span>項目名1</dt>
    <dd>これは項目1の説明文です。</dd>
  </div>
  <div class="dads-description-list__item">
    <dt><span>2.</span>項目名2</dt>
    <dd>これは項目2の説明文です。</dd>
  </div>
</dl>
