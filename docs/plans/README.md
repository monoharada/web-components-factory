# 📋 Implementation Plans

このディレクトリには、機能開発やリファクタリングの実装計画を保存します。

## 📂 構造

```
plans/
├── README.md                 # このファイル
├── feature-*.md             # 新機能の実装計画
├── refactor-*.md           # リファクタリング計画
├── fix-*.md               # バグ修正計画
└── archived/              # 完了した計画のアーカイブ
```

## 🔄 計画のライフサイクル

1. **Draft**: 初期作成状態
2. **In Review**: レビュー中
3. **Approved**: 承認済み
4. **In Progress**: 実装中
5. **Completed**: 完了
6. **Archived**: アーカイブ済み

## 📊 計画作成のベストプラクティス

### DO ✅
- 明確で測定可能なゴールを設定
- タスクを30分〜2時間の単位に分解
- リスクと依存関係を明記
- テスト戦略を含める
- 段階的な実装アプローチ

### DON'T ❌
- 曖昧な表現を使う
- 大きすぎるタスクを作る
- テスト計画を省略
- 依存関係を無視
- 楽観的すぎる見積もり

## 🏷️ ファイル命名規則

```
{type}-{date}-{short-description}.md
```

例:
- `feature-20250902-accordion-component.md`
- `refactor-20250902-css-variables.md`
- `fix-20250902-button-hover-state.md`

## 🔍 計画の検索
