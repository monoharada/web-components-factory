## 発見メソッド統計

| メソッド | 使用回数（概算） |
|---------|--------------|
| WebFetch（トップページ直接アクセス＋リンク解析） | 30回（top_page_url全件） |
| WebSearch（site:ドメイン検索によるフォールバック） | 約90回（service/article/contactの大部分） |
| サイトマップ活用 | 0回 |

### メソッド別の詳細

- **top_page_url**: 全30件をWebFetchで直接確認
- **contact_page_url**: 約10件をトップページのfooter/headerリンク解析で発見、約16件をWebSearch（`site:{domain} お問い合わせ`）で発見
- **service_page_url**: 約25件をWebSearch（`site:{domain} 児童手当`）で発見、約4件をトップページナビゲーション解析で発見
- **hub_page_url**: 約15件をトップページのグローバルナビ解析で発見、約12件をWebSearchで発見
- **article_page_url**: 約20件をWebSearch（`site:{domain} お知らせ 2026年2月`）で発見、約5件をトップページ新着情報セクション解析で発見

## 知見・パターン

### 発見しやすいページタイプ
1. **service_page_url（97%）**: 「児童手当」は全国共通の制度であり、ほぼ全自治体に専用ページが存在
2. **hub_page_url（90%）**: グローバルナビの「くらし」「子育て」カテゴリは多くの自治体で採用
3. **contact_page_url（87%）**: フッター等に設置されるケースが多い

### 発見しにくいページタイプ
1. **article_page_url（83%）**: 小規模自治体ではPDF広報誌のみ、個別HTML記事ページが存在しないケースあり
2. **contact_page_url**: 総合案内ではなく課別お問い合わせのみの自治体がある

### 自治体規模と充足率の関係
- **政令市・中核市（人口30万以上）**: 全5タイプほぼ100%発見可能
- **一般市（人口10-30万）**: 4-5タイプ発見可能（articleが見つからないケースあり）
- **離島・小規模自治体（人口5万以下）**: 2-4タイプ。特にservice/articleが不足しがち

### 270自治体拡大に向けた提言
1. 「児童手当」でのservice検索は非常に有効（97%の成功率）
2. article発見にはWebSearchの`site:`演算子が必須（トップページ解析だけでは不足）
3. 離島・小規模自治体（D層）はNOT_FOUND率が高いことを許容する設計が必要
4. CMS構造が特殊な自治体（四日市市など）は個別対応が必要
