なぜ details/summary を使うべきか？

セマンティックな利点：

  • ブラウザネイティブのアクセシビリティ機能
  • キーボード操作が自動的に実装される
  • スクリーンリーダーが正しく認識
  • JavaScriptなしでも基本機能が動作

スタイリングの柔軟性：

  • マーカーは list-style: none で簡単に非表示化
  • Shadow DOM内でも完全にカスタマイズ可能
  • CSSアニメーションも適用可能
アニメーション実装について

記事で紹介されているように、モダンCSSでは details 要素のアニメーションが可能です：

details[open] .content {
  animation: slideDown 300ms ease-out;
}

@keyframes slideDown {
  from {
    opacity: 0;
    height: 0;
  }
  to {
    opacity: 1;
    height: var(--content-height);
  }
}

この実装では、コンテンツの高さを動的に計算し、CSS変数として設定することで、スムーズなアニメーションを実現しています。
アクセシビリティの改善

スクリーンリーダーの問題解決：

以前の実装では「クリックしたときに開かない、二回クリックすると開く」問題がありました。 これは、カスタム実装のARIA属性とイベント処理の競合が原因でした。

details/summary の利点：

  • ブラウザネイティブのフォーカス管理
  • 正しいARIAロールの自動適用
  • キーボードイベントの適切な処理
  • タッチデバイスでの最適化された動作
実装のベストプラクティス

推奨される実装方法：

  1. セマンティックHTMLを優先： details/summary のようなネイティブ要素を活用
  2. プログレッシブエンハンスメント： 基本機能はHTMLで、拡張機能はJSで
  3. アクセシビリティファースト： デフォルトでアニメーション無効
  4. パフォーマンス最適化： will-change と GPU アクセラレーション

この実装では、これらすべてのベストプラクティスを適用しています。

🎨 アニメーションタイプ

スムーズアニメーション

スムーズなアニメーション
ease-out カーブを使用した滑らかな展開・折りたたみアニメーション。 ユーザーエクスペリエンスを向上させながら、過度な装飾を避けています。

バウンスアニメーション

バウンスアニメーション
cubic-bezier を使用したスプリング効果。 よりダイナミックな印象を与えたい場合に使用します。

アニメーションなし（デフォルト）

アクセシビリティファースト
モーション酔いや認知障害を持つユーザーのために、 デフォルトではアニメーションを無効化しています。

💻 コード例

// Details/Summary ベースの実装
class DadsAccordionItemDetails extends WebComponent {
  #details?: HTMLDetailsElement;
  
  template = html\`
    <details>
      <summary class="accordion-summary">
        <span class="accordion-icon">...</span>
        <slot name="header"></slot>
      </summary>
      <div class="accordion-content">
        <slot name="content"></slot>
      </div>
    </details>
  \`;
  
  // スタイリング - マーカーを非表示
  styles = css\`
    summary {
      list-style: none;
    }
    summary::-webkit-details-marker {
      display: none;
    }
  \`;
}

使用方法： 

<dads-accordion-details animation="smooth">
  <dads-accordion-item-details>
    <div slot="header">質問</div>
    <div slot="content">回答</div>
  </dads-accordion-item-details>
</dads-accordion-details>
