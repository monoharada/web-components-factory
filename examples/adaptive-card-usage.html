Basic Card

Outlined Variant

.example-basic adaptive-card {

  --adaptive-card-radius: 1rem;

  --adaptive-card-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);

2. Advanced Styling with CSS Parts

Using CSS Parts to style internal elements directly.

Gradient Card

This card uses CSS Parts to apply a gradient background and style individual sections.

 
/* CSS */
adaptive-card::part(base) {
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  color: white;
}

adaptive-card::part(header) {
  border-bottom: 2px solid rgba(255, 255, 255, 0.2);
}

Key Improvements

CSS Custom Properties Strategy

  • Comprehensive property set: Every visual aspect is customizable via CSS properties
  • Semantic naming: Properties follow --adaptive-card-* pattern for clarity
  • Design token integration: Falls back to global design tokens (--design-token-*)
  • State modifiers: Separate properties for hover, active, selected, and disabled states
  • Section-specific properties: Granular control over media, header, content, and actions

CSS Parts Implementation

  • Granular parts: Multiple parts exposed for each section (container + inner)
  • Semantic aliases: Parts have both specific and general names
  • Layout flexibility: Parts can be targeted for complex grid/flex layouts
  • State-based styling: Parts work with attribute selectors for conditional styling

Performance Optimizations

  • CSS containment: contain: layout style for rendering performance
  • Efficient selectors: Using :where() to maintain specificity
  • Motion preferences: Respects prefers-reduced-motion
  • High contrast support: Enhanced borders in high contrast mode

Design System Integration

  • Token cascade: Component properties fall back to design system tokens
  • Predictable API: Consistent property naming across components
  • Theme flexibility: Easy to create theme variations without modifying component
  • Dark mode ready: Automatic adaptation with CSS media queries
