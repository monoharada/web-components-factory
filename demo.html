1. デフォルト設定（アクセシビリティファースト）

デフォルトではアニメーションが無効化されています。これは、モーション酔いや認知障害を持つユーザーのアクセシビリティを優先した設計です。

デジタル庁とは何ですか？
デジタル庁は、2021年9月1日に設置された日本の行政機関です。 デジタル社会形成の司令塔として、国・地方行政のデジタル化を推進し、 誰一人取り残されないデジタル社会の実現を目指しています。
アクセシビリティファーストとは？
アクセシビリティファーストは、すべてのユーザーが等しく情報にアクセスできることを 最優先に考える設計思想です。視覚・聴覚・運動・認知などの障害の有無に関わらず、 誰もが使いやすいサービスを提供することを目標としています。
WCAG 2.1 AAとは？
Web Content Accessibility Guidelines (WCAG) 2.1のAAレベルは、 ウェブコンテンツのアクセシビリティ基準です。色のコントラスト比、 キーボード操作、スクリーンリーダー対応など、幅広い要件を満たす必要があります。

</dads-accordion>

2. アニメーションタイプ

ユーザーが明示的に選択した場合のみ、アニメーションを有効化できます。 respect-motion-preference属性を追加すると、OSのモーション削減設定を尊重します。

スムーズアニメーション

スムーズなアニメーション例
このアコーディオンは、スムーズなアニメーションで開閉します。 ただし、OSでモーション削減が有効な場合は自動的に無効化されます。
パフォーマンス最適化
CSS Transitionを使用し、GPUアクセラレーションを活用して 60fpsの滑らかなアニメーションを実現しています。

バウンスアニメーション

バウンスアニメーション例
スプリング効果のあるアニメーションで、より動的な印象を与えます。 エンターテインメント性の高いコンテンツに適しています。 
<!-- スムーズアニメーション + モーション設定尊重 -->
<dads-accordion animation="smooth" respect-motion-preference>
  ...
</dads-accordion>

<!-- バウンスアニメーション -->
<dads-accordion animation="bounce">
  ...
</dads-accordion>

3. 複数展開モード

allow-multiple属性を追加すると、複数のアイテムを同時に展開できます。

複数展開可能アイテム 1
このアコーディオンは複数のアイテムを同時に展開できます。 他のアイテムをクリックしても、このアイテムは開いたままです。
複数展開可能アイテム 2
複数展開モードは、比較や並列的な情報表示に適しています。 ユーザーが必要な情報を一度に確認できます。
複数展開可能アイテム 3
デフォルトでは単一展開モードで、一つのアイテムのみ展開されます。 これは画面スペースの効率的な利用とフォーカスの明確化に役立ちます。 
<dads-accordion allow-multiple animation="smooth">
  <dads-accordion-item expanded>...</dads-accordion-item>
  <dads-accordion-item expanded>...</dads-accordion-item>
</dads-accordion>

📋 申請手続きについて

必要書類

  • 本人確認書類（運転免許証、マイナンバーカードなど）
  • 住民票の写し（3ヶ月以内のもの）
  • 申請書（オンラインで作成可能）

申請方法

  1. オンライン申請システムにアクセス
  2. 必要事項を入力
  3. 書類をアップロード
  4. 申請内容を確認して送信

処理期間：通常3〜5営業日
手数料：無料
