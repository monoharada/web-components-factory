# ボタンコンポーネント要件定義書

## 1. 概要
デジタル庁デザインシステムv2.7.0準拠のボタンコンポーネントを作成する。

- **Node ID**: 8268-28289

## 3. コンポーネント要件

### 3.1 バリアント（外観）
1. **Solid Fill（塗りつぶし）**
   - 背景色: #0017c1
   - テキスト色: 白
   - ホバー時: 背景色が暗くなる
   - フォーカス時: 黄色のリング + 黒枠

2. **Outlined（アウトライン）**
   - 背景色: 透明
   - テキスト色: #0017c1
   - 枠線: 2px solid #0017c1
   - ホバー時: 背景色が薄い青になる

3. **Text（テキストのみ）**
   - 背景色: 透明
   - テキスト色: #0017c1
   - 枠線: なし
   - ホバー時: 背景色が薄い青になる

### 3.2 サイズ
1. **X-Small**
   - 高さ: 28px
   - パディング: 4px 8px
   - フォントサイズ: 12px

2. **Small**
   - 高さ: 32px
   - パディング: 8px 12px
   - フォントサイズ: 14px

3. **Medium（デフォルト）**
   - 高さ: 40px
   - パディング: 12px 16px
   - フォントサイズ: 16px

4. **Large**
   - 高さ: 48px
   - パディング: 16px 24px
   - フォントサイズ: 18px

### 3.3 状態
1. **Default**: 通常状態
2. **Hover**: マウスオーバー時
3. **Active**: クリック時
4. **Focus**: フォーカス時（キーボード操作）
5. **Disabled**: 無効化時

### 3.4 アクセシビリティ要件
- WCAG 2.2 AA準拠
- キーボード操作対応（Tab, Enter, Space）
- フォーカス表示（黄色背景 + 黒枠）
- スクリーンリーダー対応（適切なARIA属性）
- コントラスト比 4.5:1以上

### 3.5 技術仕様
- **タグ名**: `dads-button`
- **基底クラス**: `WebComponent`
- **Shadow DOM**: 使用
- **::part()**: カスタマイズ用に公開
- **スロット**: デフォルトスロット（テキスト）、iconスロット（オプション）

## 4. 属性とプロパティ

### 4.1 属性
- `variant`: "solid" | "outlined" | "text" (デフォルト: "solid")
- `size`: "x-small" | "small" | "medium" | "large" (デフォルト: "medium")
- `disabled`: boolean (デフォルト: false)
- `type`: "button" | "submit" | "reset" (デフォルト: "button")
- `full-width`: boolean (デフォルト: false)

### 4.2 イベント
- `click`: クリック時に発火
- カスタムイベントのdetailに variant と size を含める

## 5. デザイントークン活用
- セマンティックトークン（意味的な値）
- ローカルコンポーネントトークン（カスタマイズ可能）
- CSS変数での上書き対応

## 6. パフォーマンス要件
- 初回レンダリング: 10ms以下
- インタラクション応答: 100ms以下
- バンドルサイズ: 5KB以下（gzip後）

## 7. ブラウザサポート
- Chrome/Edge 最新版
- Firefox 最新版
- Safari 最新版

## 8. 実装優先順位
1. **Phase 1（MVP）**: 基本的な見た目とクリックイベント
2. **Phase 2**: 全バリアント・サイズ対応
3. **Phase 3**: アクセシビリティ完全対応
4. **Phase 4**: アイコン対応
