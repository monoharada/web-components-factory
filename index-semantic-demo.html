使用方法

基本的な使用例
<adaptive-card aria-label="カードの説明">
  <h3 slot="title">カードタイトル</h3>
  <span slot="subtitle">サブタイトル</span>
  <img slot="media" src="image.jpg" alt="画像の説明">
  <p slot="content">メインコンテンツ</p>
  <div slot="details">詳細情報</div>
  <button slot="actions">アクション</button>
</adaptive-card>
CSS カスタムプロパティ
adaptive-card {
  --card-max-width: 400px;
  --card-background: #ffffff;
  --card-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
  --title-color: #1f2937;
  --primary-button-background: #2563eb;
}
