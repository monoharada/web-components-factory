# Card Example 5 追加プラン（縦/横切替カード）

## 目標
DADS 作例5（縦/横切替できるカード）を `/?component=card` のデモに追加し、DADS Storybookと同等の見た目・挙動を再現する。

## 背景
作例5は「水平と垂直が切り替えられるカード」であり、既存の作例1〜3とは異なるレイアウト切替要素が必要。

## スコープ
- やること：
  - `src/demos/showcase-components.ts` に作例5セクションを追加
  - スイッチで縦/横切替のUIを用意し、`dads-card` の `layout` 属性を切替
  - DADSの見た目（余白/文字/画像/ボタン/境界）を再現
  - VRTを追加または既存VRTに作例5を含める
- やらないこと：
  - `dads-card` 本体実装の変更
  - 既存作例1〜3のレイアウト変更

## 前提 / 制約
- DADSページ/figmaが現時点で参照できないため、見た目はユーザー提供のスクリーンショット/仕様を基準にする
- CSSは `css-writing-rules` を遵守（トークン優先・!important禁止・1階層ネスト）

## 変更内容（案）
### データ / バックエンド
- 該当なし

### UI / UX
- 作例5セクションを作例3の後に追加
- 切替UIは `dads-switch` で実装（縦/横）
- 切替に応じて `dads-card` の `layout="horizontal"` を付け外し（縦は属性なし）
- DADSのカードデザイン（タイトル/本文/画像/CTA/余白）を再現

### その他（Docs/Marketing/Infra など）
- 必要に応じて `e2e-evidence/` に作例5のVRT追加

## 受入基準
- [ ] 作例5がカードデモに追加されている
- [ ] 縦/横の切替操作でカードのレイアウトが変化する
- [ ] DADS Storybookの作例5と見た目が一致する（余白/文字/ボタン/画像位置）
- [ ] VRTがグリーン

## リスク / エッジケース
- 参照ソース（Storybook/figma）が取得できないため、再現精度がユーザー提供情報に依存
- レイアウト切替のUIがDADSの想定と異なる可能性
- 画像アセットが未提供の場合、仮画像との差異が出る
