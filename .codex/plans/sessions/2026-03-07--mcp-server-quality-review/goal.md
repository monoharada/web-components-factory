# Goal

## Goal Statement
`packages/mcp-server` のコード品質を監査し、特に `MCP としての正確性`、`パフォーマンス`、`保守性` の観点で、修正優先度付きの改善計画を確定する。

## Success Criteria
- KR-01: MCP 仕様または SDK 前提に反する実装差分を、再現手順付きで特定できる。
- KR-02: 現状性能の実測値と、将来ボトルネックになりやすい箇所を切り分けられる。
- KR-03: 保守性を下げている責務集中、契約 drift、テスト欠落を整理できる。
- KR-04: 修正順序、検証コマンド、回帰観点を含む remediation plan を定義できる。

## Hard Constraints
- F-01: 今回は監査と計画のみを行い、実装コードは変更しない。
- F-02: 指摘は `packages/mcp-server/**` を中心に、必要最小限の依存コードと仕様根拠だけを見る。
- F-03: 指摘は再現可能な事実ベースに限定し、推測だけで severity を上げない。

## Definition of Done
- D-01: MCP 正確性の主要問題を、根拠付きで列挙できる。
- D-02: パフォーマンスの現状値と改善余地を切り分けられる。
- D-03: 保守性・テスト面の主要負債を特定できる。
- D-04: 修正順序と検証計画を文書化し、実装着手可否を判定できる。
