基本情報について

これは基本情報のコンテンツです。デジタル庁デザインシステムに基づいた実装になっています。

Shadow DOM と ::part() を使用することで、外部からのスタイル適用が可能です。

 技術仕様について

Web Components 標準に準拠した実装です。

  • Custom Elements
  • Shadow DOM
  • CSS Parts API
  • Slot API
 アクセシビリティについて

WCAG 2.1 AA準拠を目指しています。

キーボード操作、スクリーンリーダー対応、高コントラストモードをサポートしています。

複数展開可能なアコーディオン

最初から開いている項目

expanded 属性により、初期状態で開いています。

 通常の項目

allow-multiple 属性により、複数の項目を同時に開けます。
